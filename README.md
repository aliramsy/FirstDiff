# FirstDiff: One-Step Diffusion-Based Anomaly Detection for Multivariate Time Series

This repository contains the implementation of **FirstDiff**, a diffusion-based framework for multivariate time-series anomaly detection.

FirstDiff is based on the observation that the **predicted diffusion noise at the initial reverse-diffusion evaluation already provides highly informative anomaly representations**. Instead of completing the full reverse-diffusion trajectory to obtain a final reconstruction, FirstDiff can perform anomaly inference from a single denoising-network evaluation, substantially reducing the computational cost of diffusion-based anomaly detection.

The method uses a **Diffusion Transformer (DiT)** as the denoising backbone and evaluates anomaly representations using statistical distance measures, including Mahalanobis distance.

---

## Overview

Conventional diffusion-based anomaly detection methods typically perform multiple denoising evaluations before producing a reconstructed or imputed time series. FirstDiff investigates whether the information produced at the beginning of the denoising process can already be used for anomaly detection.

The core idea is:

```text
Multivariate time-series window
            │
            ▼
       Forward diffusion
            │
            ▼
          X_T
            │
            ▼
  Diffusion Transformer
            │
            ▼
 Predicted diffusion noise
            │
            ▼
 Statistical anomaly score
            │
            ▼
      Anomaly detection
```

The proposed one-step inference procedure requires only the initial denoising-network evaluation rather than completing the entire reverse-diffusion trajectory.

---

## Key Features

* **One-step diffusion inference** for anomaly detection.
* Uses **predicted diffusion noise** as an anomaly representation.
* Designed for **multivariate time-series anomaly detection**.
* Uses a **Diffusion Transformer (DiT)** as the denoising backbone.
* Statistical anomaly modeling using normal validation data.
* **Mahalanobis-distance-based anomaly scoring**.
* Supports reconstruction-based anomaly detection for comparison.
* Supports hybrid anomaly-detection variants using complementary anomaly signals.
* Evaluated on five public multivariate time-series anomaly-detection benchmarks:

  * SMD
  * SMAP
  * SWaT
  * MSL
  * PSM

## Method

### Diffusion Model

FirstDiff uses a diffusion process to perturb normal time-series windows and trains a neural network to predict the corresponding diffusion noise.

Let $\mathbf{X}_t$ denote a noisy time-series representation at diffusion timestep $t$. The denoising network predicts the diffusion noise as

$$
\hat{\boldsymbol{\epsilon}}
===========================

\epsilon_\theta(\mathbf{X}_t,t).
$$

The central observation of FirstDiff is that the predicted noise obtained at the **initial reverse-diffusion evaluation** already contains useful information for distinguishing normal and anomalous behavior.

Instead of executing the complete reverse process,

```text
X_T → X_{T-1} → ... → X_0
```

FirstDiff can perform anomaly inference using:

```text
X_T → Denoising Network → Predicted Noise → Anomaly Score
```

This allows anomaly detection after a single denoising-network evaluation.

---

## Statistical Anomaly Modeling

FirstDiff models normal denoising behavior using representations obtained from normal validation data.

For the predicted-noise representation, the sample mean and covariance are estimated as

$$
(\boldsymbol{\mu}*{\epsilon},
\boldsymbol{\Sigma}*{\epsilon}).
$$

A Gaussian reference model is used as a tractable approximation to the empirical distribution of predicted denoising representations under normal operation.

Given a test representation $\mathbf{z}$, the Mahalanobis distance is computed as

$$
D_M(\mathbf{z}) =
\sqrt{
(\mathbf{z}-\boldsymbol{\mu}*{\epsilon})^\top
\boldsymbol{\Sigma}*{\epsilon}^{-1}
(\mathbf{z}-\boldsymbol{\mu}_{\epsilon})
}.
$$

Large deviations from the normal reference model indicate anomalous behavior.

---

## Denoising Representations

FirstDiff investigates multiple representations generated by the diffusion model:

1. **Predicted diffusion noise**
2. **Prediction residual**
3. **Final reconstruction**

The predicted-noise and residual representations can be obtained from the initial denoising evaluation, while reconstruction-based detection uses the reverse-diffusion process.

These representations enable comparisons between:

```text
One-step predicted-noise detection
```

```text
One-step residual-based detection
```

and

```text
Full reverse-diffusion reconstruction
```

---

## Hybrid Anomaly Detection

The different representations generated during diffusion can provide complementary information.

FirstDiff therefore supports hybrid anomaly-detection configurations combining:

* predicted diffusion noise;
* prediction residuals;
* reconstruction-based anomaly scores;
* combinations of complementary one-step signals;
* combinations of one-step signals with reconstruction-based signals.

These variants are used to investigate whether complementary anomaly representations can improve detection performance.

## Data Preprocessing

Each dataset is standardized using `StandardScaler`.

The scaler is fitted using the training data:

```python
scaler = StandardScaler()
scaler.fit(train_raw)
```

The resulting scaler is then used by the training, validation, and test datasets.

For CSV-based datasets, dataset-specific non-feature columns are removed before constructing the multivariate time-series representation.

## Window Configuration

The default configuration uses:

```text
Main window size:       96
Training window size:   128
Training stride:        64
Validation stride:      96
Test stride:            96
```

The main anomaly-detection window contains $W \times K$ values, where $W=96$ is the temporal window length and $K$ is the number of sensors/features.

## Model Architecture

The default denoising backbone is an **Unconditional Time-Series Diffusion Transformer**:

```python
UnconditionalTimeSeriesDiT(
    target_seq_len=WINDOW_SIZE,
    num_sensors=channels,
    hidden_dim=D_MODEL,
    num_heads=HEAD_NUMBER,
    num_layers=DiT_num_layers
)
```

The default model configuration is:

| Parameter          | Value |
| ------------------ | ----: |
| Window size        |    96 |
| Hidden dimension   |   256 |
| Attention heads    |     8 |
| Transformer layers |     6 |
| Diffusion steps    |   100 |
| Batch size         |   128 |
| Training epochs    |    15 |

Dataset-specific sensor dimensions are:

```python
CHANNELS = {
    'MSL': 55,
    'SMAP': 25,
    'SWaT': 51,
    'PSM': 25,
    'SMD': 38
}
```

## Training

The training script trains a separate model for each dataset.

The supported datasets are:

```python
datasets = ["SMD", "SMAP", "SWaT", "MSL", "PSM"]
```

Run:

```bash
python train.py
```

For each dataset, the pipeline:

1. Loads the training data.
2. Fits the standardization parameters using the training data.
3. Constructs training, validation, and test datasets.
4. Creates PyTorch dataloaders.
5. Initializes the diffusion process.
6. Initializes the Diffusion Transformer.
7. Trains the model using `Solver`.
8. Releases model and GPU memory before processing the next dataset.

The core training procedure is:

```python
solver = Solver(
    uncdit,
    train_dataloader,
    val_dataloader,
    test_dataloader,
    diffusion=diffusion,
    experiment=experiment,
    device=device,
    gpu_id=GPU_ID,
    dataset=dataset,
    enumer=i
)

solver.train(EPOCHS)
```

## Inference

### One-Step Inference

The primary FirstDiff detector uses the predicted diffusion noise from the initial reverse-diffusion evaluation.

The procedure is:

```text
Input time-series window
          │
          ▼
    Forward diffusion
          │
          ▼
Initial reverse-diffusion evaluation
          │
          ▼
  Predicted diffusion noise
          │
          ▼
 Statistical anomaly score
          │
          ▼
     Anomaly decision
```

Only one denoising-network evaluation is required for the proposed one-step detector.

### Full Reverse-Diffusion Inference

For reconstruction-based anomaly detection, the complete reverse-diffusion trajectory can be executed to produce a reconstructed time series.

This provides a comparison between one-step anomaly representations and conventional reconstruction-based diffusion inference.

---

## Computational Efficiency

A key motivation of FirstDiff is to reduce the computational cost of diffusion-based anomaly detection.

A full reverse-diffusion procedure requires repeated denoising-network evaluations:

```text
T → T-1 → T-2 → ... → 0
```

whereas one-step FirstDiff inference requires only the initial denoising-network evaluation:

```text
T → Predicted Noise → Anomaly Score
```

Therefore, the proposed one-step detector avoids executing the remaining reverse-diffusion evaluations.

The repository includes inference-time evaluation scripts for comparing one-step and full reverse-diffusion inference.
